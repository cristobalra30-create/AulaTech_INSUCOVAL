# AulaTech INSUCOVAL

### Plataforma web de información sobre los laboratorios de computación

## Descripción del proyecto

**AulaTech INSUCOVAL** es un proyecto de desarrollo web creado para presentar y organizar información sobre los laboratorios de computación del Instituto Superior de Comercio Francisco Araya Bennett de Valparaíso.

La plataforma tiene como propósito facilitar el acceso a información sobre los cinco laboratorios de computación del establecimiento, permitiendo a los usuarios conocer sus características, recursos tecnológicos y las actividades académicas que se pueden desarrollar en estos espacios.

El sitio cuenta con una página principal desde la cual se puede acceder a la información general de los laboratorios, conocer el equipamiento tecnológico y navegar hacia páginas individuales dedicadas a cada laboratorio. Además, incorpora secciones complementarias como una página de contacto y otra de presentación personal.

El proyecto busca ofrecer una experiencia de navegación clara, organizada y visualmente atractiva, utilizando un diseño adaptable a diferentes tamaños de pantalla y una identidad visual basada en tonos oscuros, azul noche y amarillo.

## Objetivos

- Centralizar la información de los laboratorios de computación del establecimiento.
- Facilitar la navegación entre las distintas secciones del sitio web.
- Presentar información sobre los computadores, periféricos y otros recursos tecnológicos.
- Describir las actividades educativas y prácticas relacionadas con la informática.
- Implementar un diseño moderno, accesible y adaptable a dispositivos móviles.
- Aplicar conocimientos de desarrollo web mediante HTML, CSS y JavaScript.

## Características principales

- **Página de inicio:** presenta el proyecto y permite acceder a sus diferentes secciones.
- **Información de los laboratorios:** incluye páginas individuales para los cinco laboratorios de computación.
- **Equipamiento tecnológico:** muestra información general sobre los recursos utilizados en las actividades académicas.
- **Página de contacto:** incorpora información de contacto y un formulario visual para consultas.
- **Página «Sobre mí»:** permite presentar al desarrollador, sus intereses, habilidades y proyectos.
- **Diseño responsive:** adapta la distribución del contenido a computadores, tabletas y teléfonos móviles.
- **Iconografía:** utiliza Lucide Icons para representar visualmente las secciones y funciones del sitio.
- **Navegación interactiva:** incorpora un menú adaptable, animaciones y desplazamiento suave entre secciones.

## Tecnologías utilizadas

| Tecnología | Uso en el proyecto |
|---|---|
| HTML5 | Estructura y organización del contenido. |
| CSS3 | Diseño visual, colores, tarjetas, animaciones y adaptación responsive. |
| JavaScript | Interactividad, menú móvil, animaciones y funciones de navegación. |
| Lucide Icons | Iconos para mejorar la presentación visual. |

## Diseño e interfaz

La identidad visual utiliza una combinación de negro, azul noche y amarillo para mantener una apariencia tecnológica y coherente con el propósito educativo del proyecto.

El diseño incorpora tarjetas informativas, botones de navegación, iconos y efectos visuales que ayudan a organizar el contenido y facilitan la interacción con el sitio.

## Instalación y ejecución

1. Descarga o copia los archivos del proyecto en una carpeta.
2. Comprueba que todos los archivos HTML, CSS y JavaScript estén ubicados correctamente.
3. Verifica que las imágenes utilizadas estén guardadas en las rutas correspondientes.
4. Abre el archivo `index.html` en un navegador web.
5. Navega por las diferentes secciones para consultar la información disponible.

**Requisito:** se necesita conexión a internet para cargar los iconos de Lucide desde su CDN, salvo que se configure una copia local.

## Alcance y mejoras futuras

AulaTech INSUCOVAL constituye una base para la presentación digital de los laboratorios de computación. Entre las posibles mejoras futuras se encuentran:

- Incorporar fotografías reales de cada laboratorio.
- Agregar información específica y actualizada sobre el equipamiento disponible.
- Conectar el formulario de contacto con un servicio de envío de mensajes.
- Implementar una base de datos para administrar la información.
- Añadir un panel de administración para actualizar el contenido.
- Mejorar la accesibilidad y optimizar el rendimiento del sitio.
